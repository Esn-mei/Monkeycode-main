# Triage Labels

Engineering skills 使用以下 canonical roles。右侧字符串是本仓库本地 issue 的实际 `Status:` 值。

| Canonical role | 本仓库状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待评估` | Maintainer 需要评估 |
| `needs-info` | `待补充` | 等待 reporter 补充信息 |
| `ready-for-agent` | `可交Agent` | 需求完整，可由 AFK agent 执行 |
| `ready-for-human` | `需人工` | 需要人工实现或决策 |
| `wontfix` | `不处理` | 不会继续处理 |

当 skill 提及 canonical role 时，必须写入本表对应的中文状态值。
